Häufige Fragen

Was ist ein Wohnungsmodell mit Wohnungsfinder?

Ein interaktives 3D-Modell eines Gebäudes oder Quartiers, eingebunden auf der Website des Bauträgers. Interessenten filtern verfügbare Wohnungen nach Fläche, Etage, Zimmeranzahl und Preis und sehen die gewählte Einheit direkt im Modell.

Was kostet das Modell?

Der Preis hängt von der Anzahl der Gebäude und Wohneinheiten sowie vom Umfang der Anpassung ab. Ein kostenloses Angebot erhalten Sie innerhalb von 24 Stunden nach Eingang der wichtigsten Projektdaten — füllen Sie einfach das Formular aus.

Wie lange dauert die Umsetzung?

In der Regel 10 bis 15 Arbeitstage, abhängig von der Anzahl der Gebäude und der Vollständigkeit der vom Bauträger gelieferten Unterlagen.

Funktioniert das Widget auf Smartphone und Tablet?

Ja. Das Modell ist vollständig responsiv und funktioniert auf Mobilgeräten, Desktops und Touchscreens im Vertriebsbüro.

Kann ich die Verfügbarkeit selbst ändern?

Ja. Den Status jeder Wohnung (frei, reserviert, verkauft) pflegen Sie in einer freigegebenen Excel- oder Google-Tabelle, oder das Modell übernimmt ihn direkt aus Ihrem CRM. Die Änderung erscheint automatisch im Widget — ohne Eingriff in den Code Ihrer Website.

Lässt sich das Modell an unser CRM anbinden?

Ja. Wenn Ihr Vertriebssystem oder CRM eine Wohnungsliste bereitstellt (per API oder XML/CSV-Export), übernimmt das Modell Status und Preise automatisch. Integrationen kalkulieren wir individuell.

Ersetzt das Modell den Vertrieb?

Nein. Es unterstützt den Vertrieb, indem Interessenten ihre Auswahl schon vor dem ersten Kontakt eingrenzen. Verkaufsgespräche werden dadurch kürzer und gezielter.

Kann ich das Modell auf mehreren Seiten einbinden?

Ja. Dasselbe Widget kann auf der Projektstartseite, auf Seiten einzelner Gebäude und in Marketingmaterialien eingesetzt werden — ohne zusätzliche Umsetzungskosten.
